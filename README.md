# Scraping and Sentiment Analysis

A pipeline that scrapes Google Play Store reviews and runs sentiment analysis on them using traditional NLP techniques.

---

## Project Structure

```
scrapping_and_sentiment_analysis/
│
├── scraper.py                        # Scrapes reviews from Google Play
├── data_cleaner.py                   # Cleans and filters scraped reviews
├── sentiment_analyzer.py             # Runs sentiment analysis on cleaned data
├── instagram_reviews.csv             # Raw scraped reviews (generated by scraper)
├── instagram_reviews_healed_emojis.csv  # Cleaned reviews (generated by cleaner)
├── requirements.txt
└── README.md
```

## Usage

### Step 1 — Configure the Scraper

Before running the scraper you need to provide three things from your browser session. Open Chrome, go to the Google Play Store, open DevTools (F12) → Network tab, trigger a review load, and find the `batchexecute` POST request.

In `scraper.py`, update the following:

**Cookies** — copy the entire `cookie` header value from the request and update the `COOKIES` dict.

**XSRF Token** — find the `at` field in the request payload (Form Data tab) and update:
```python
XSRF_TOKEN = "your_token_here"
```

**Session params** — copy `f.sid` and `bl` values from the request URL and update in `scrape_reviews()`:
```python
"f.sid": "your_f.sid_here",
"bl":    "your_bl_here",
```

> ⚠️ Cookies and the XSRF token expire after a few hours. If the scraper returns no reviews, refresh these values from your browser.

### Step 2 — Configure Scrape Target

In `scraper.py` at the bottom, set your target app and review count:

```python
APP_ID  = "com.instagram.android"   # any Google Play app package ID
TOTAL   = 2000                       # number of reviews to scrape
SORT    = "newest"                   # "newest" | "relevant" | "rating"
OUTFILE = "instagram_reviews.csv"
```

### Step 3 — Run the Scraper

```bash
python scraper.py
```

Output: `instagram_reviews.csv`

---

### Step 4 — Clean the Data

```bash
python data_cleaner.py
```

This fixes mojibake encoding issues in emojis, filters non-English reviews, and separates emoji characters from text.

Output: `instagram_reviews_healed_emojis.csv`

---

### Step 5 — Run Sentiment Analysis

```bash
python sentiment_analyzer.py
```

This trains a TF-IDF + Logistic Regression classifier on the cleaned reviews and prints accuracy.

## How It Works

### Scraper
- Sends POST requests to Google Play's internal `batchexecute` RPC endpoint
- Paginates through reviews using a continuation token returned in each response
- Extracts review ID, name, rating, text, timestamp, thumbs up count, and app version

### Data Cleaner
- Fixes mojibake (corrupted UTF-8 characters) in emojis using latin-1 re-encoding
- Detects and filters non-English reviews using `langdetect`
- Separates emoji characters into their own column

### Sentiment Analysis
- Maps star ratings to 3 classes: `negative` (1-2), `neutral` (3), `positive` (4-5)
- Preprocesses text: tokenization, stopword removal (keeping negation words), POS tagging
- Vectorizes using TF-IDF with bigrams (`ngram_range=(1,2)`)
- Trains Logistic Regression classifier
- Current accuracy: **~82.9%**

## Notes

- Scraping is rate-limited with a 1.5s delay between batches to avoid being blocked
- The scraper requires valid Google session cookies — these are tied to your Google account
- Do not commit your cookies or XSRF token to version control
- Tested on Python 3.12, Windows 11
- Commented transformers and fasttext from requriements, uncomment if needed.
